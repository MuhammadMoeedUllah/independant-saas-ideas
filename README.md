# Independent SaaS ideas

Research on SaaS ideas built around new US state-level compliance deadlines.

## Reports

- [State compliance SaaS deep dive](reports/State%20compliance%20SaaS%20deep%20dive.md) (Oct 9, 2026): competitors, business feasibility, product feasibility and launch plans for four ideas, with a scoring matrix and ranked recommendation.

| Rank | Idea | Verdict |
|---|---|---|
| 1 | California DROP / Delete Act engine for small data brokers | Build, reshaped as audit-evidence and suppression ops (not a 45-day filer) |
| 2 | Pay-transparency job-posting exposure scanner | Build second, reshaped as a cure-clock and copy-provenance tool; validate with defense counsel first |
| 3 | PFAS proof-of-absence network + geo-fenced catalogs | Highest upside; start with rules engine + checkout blocking, gate the network on lab sharing rights |
| 4 | Packaging EPR fee simulator via converters | Don't build unless converters will pay; otherwise pitch as an ERP integration |
